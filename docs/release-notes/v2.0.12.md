## mabi-patcher 2.0.12

### New
- **Apply mods to the game.** Installed website and community mods now reach the game. mabi-patcher builds `package\uotiara_00001.it` the way UOTiaraPack.bat does: the loose uotiara files, then every installed mod on top. It runs 3 seconds after an install, removal or community change, and from the new **Apply to Game** button. The CLI has `mabi-patcher apply-mods -g <game>`. 412 mods apply in about 9 seconds. The first replace keeps `uotiara_00001.it.bak`, and a mod with a bad entry is skipped while the others install.
- **Website mods catalog with versions.** Every revision of a mod is listed with a version picker. Installing needs no website account: files come from GitHub `shaggyze/uotiara` and are checked against the catalog sha256.
- **Optional website account.** Sign in from the Mods tab or the Browser tab. Saved picks sync with your account, and local `.mod` files get an Upload button.
- **Browser tab** with multiple tabs and a Tampermonkey-compatible userscript runner. Scripts load from `userscripts\` beside the exe; a Tampermonkey backup `.zip` or a single `.user.js` imports from the Scripts panel.
- **My Community Mods.** Connect with a connection key (kept in Windows Credential Manager) to sync your approved private mods, with SHA-256 and size checks.
- **Startup chain.** Startup runs self-update, website mod updates, the game file check and an optional game launch in order, each behind its own setting.
- **Layout is saved in config.json:** sidebar state and the list, console and 3D preview divider sizes.

### Fixed
- Self-update and the game update no longer run at the same time, so a self-update cannot restart the app mid-patch.
- Userscripts on pages that wrap browser functions (New Relic) no longer throw "Illegal invocation".
- Session keep-alive stops retrying autologin every 10 minutes for a profile with no saved token.
- Community sync names the cause of an error, logs it once and retries once when the site resets the connection.
- uotiara sync skips archived website mods and falls back to the latest version when a saved pick is no longer offered.
